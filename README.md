# BlueClick

BlueClick is a free Android app that turns your phone into a Bluetooth remote for TVs, computers, tablets and phones: TV remote, trackpad, keyboard, presentation clicker, camera shutter, media keys and gamepad, with a preset for each device. No adverts, no account and no internet permission.
